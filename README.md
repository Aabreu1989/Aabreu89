## 💎 A Visão
MIRA (Migrants' Intelligent Rights Assistant) é o mais avançado ecossistema de apoio a imigrantes em Portugal. Desenvolvido para oferecer **Soberania de Informação** e **Empoderamento Comunitário**, o MIRA combina IA agêntica de ponta com uma interface de luxo e uma infraestrutura robusta.

## 👑 Pilares da Soberania (Imperial Design)
O MIRA V2026 segue a filosofia **Imperial Design**, garantindo uma experiência premium e intuitiva:

*   **Fundo Negro Premium (#0A0A0A)**: Um ambiente de foco absoluto e elegância.
*   **Cantos Imperial (2.5rem)**: Uma estética moderna e fluida em todos os módulos.
*   **Glassmorphism**: Interfaces translúcidas que criam profundidade e hierarquia visual.
*   **Micro-Animações**: Transições suaves que guiam o utilizador sem atrito.

## 🧠 Core Intelligence: Saber IA
O cérebro do MIRA é alimentado por modelos neurais calibrados para a realidade legislativa de 2026:
*   **DNA Jurídico**: Foco total na nova lei (Art. 88/89 extintos).
*   **AIMA Insights**: Diretrizes do CEO e fontes oficiais do governo integradas via RAG.
*   **Clarification Gate**: Diálogo proativo para garantir que o contexto do utente é compreendido antes do conselho.

## 📍 O Ecossistema
O MIRA é um império de 6 braços funcionais:
1.  **MIRA CHAT**: Assistente IA vocal e textual com reposta ultrarrápida (0.8s avg).
2.  **MAPA DE SERVIÇOS**: Localização dinâmica de pontos de apoio, juntas de freguesia e consulados.
3.  **COMUNIDADE NOBLE**: Fórum de entreajuda com gamificação de mérito e reputação.
4.  **Cursos & Emprego**: Portal de capacitação e integração no mercado de trabalho.
5.  **Notificações & Alertas**: Sistema de integridade que avisa sobre prazos e novas leis.
6.  **ADMIN HUB**: Painel de controlo nuclear para gestão de utilizadores e injeção de saber.

## 🛠️ Tecnologias de Elite
*   **Frontend**: React + Vite (Optimized for 0ms interaction).
*   **Backend & DB**: Supabase (PostgreSQL + Edge Functions).
*   **AI Engine**: Google Gemini Pro (Agental Architect).
*   **Design**: Vanilla CSS Architecture with Imperial Tokens.

## 🚀 Instalação Local

Para administradores e engenheiros que desejam replicar o ambiente de desenvolvimento:

1.  **Clonar o Repositório**:
    ```bash
    git clone https://github.com/Aabreu89/Mira.git
    cd Mira
    ```

2.  **Instalar Dependências**:
    ```bash
    npm install
    ```

3.  **Configurar Variáveis de Ambiente**:
    Crie um ficheiro `.env.local` com as suas chaves do Supabase e Gemini API.

4.  **Lançar o Sistema**:
    ```bash
    npm run dev
    ```
